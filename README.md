# 🔬 DenseNet121 ile Meme Kanseri Teşhisi & Sınıflandırma Sistemi

Bu proje; derin öğrenme (Deep Learning) ve bilgisayarlı görü teknikleri kullanılarak medikal görüntülerden meme kanseri tespiti gerçekleştiren bir yapay zekâ uygulamasıdır. Model, **DenseNet121** mimarisi kullanılarak eğitilmiş ve **Streamlit** tabanlı etkileşimli bir web arayüzü ile sunulmuştur.

## 🛠️ Kullanılan Teknolojiler
- **Derin Öğrenme / AI:** Python, TensorFlow, Keras (DenseNet121)
- **Web Arayüzü:** Streamlit
- **Görüntü İşleme:** PIL, NumPy

## 🚀 Çalıştırma
```bash
pip install tensorflow streamlit pillow numpy
streamlit run app.py
